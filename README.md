# Moxymind Technical Task — Agentic Test Generation (C# edition)

A **C# / Playwright.NET** test suite for Task 1 (saucedemo.com UI) and Task 2 (reqres.in API), **generated by a TypeScript agent workflow** built on [Mastra](https://mastra.ai).

Two languages, each used where it's strongest:
- **TypeScript** (`src/mastra/`) — the agent orchestration layer. Mastra Studio UI, workflow with parallel steps, two reviewers, human gates.
- **C#** (`MoxymindTests/`) — the test deliverable. Visual Studio-native, MSTest + Playwright.NET, debuggable like any other .NET test suite.

## Prerequisites

- **.NET 8 SDK** (`dotnet --version` → 8.0.x or 9.x or 10.x all OK)
- **Node.js >= 20** (`node --version`)
- **Visual Studio 2022/2025** (for IDE test runner + debugger) *or* command line only
- **Anthropic API key** with access to Sonnet + Haiku models

## Setup

```bash
# One-time: Node side (for the agents)
npm install --legacy-peer-deps

# One-time: .NET side (restores NuGet + builds)
cd MoxymindTests
dotnet restore
dotnet build

# One-time: Playwright browsers (for the C# project)
powershell -ExecutionPolicy Bypass -File bin/Debug/net8.0/playwright.ps1 install

# Secrets
cd ..
cp .env.example .env
# then edit .env to set ANTHROPIC_API_KEY
```

## Running the tests

```bash
# From repo root — all tests
cd MoxymindTests
dotnet test

# Only UI
dotnet test --filter "FullyQualifiedName~UI"

# Only API
dotnet test --filter "FullyQualifiedName~API"
```

### In Visual Studio

1. Open `MoxymindTests/MoxymindTests.csproj` (or create a solution containing it)
2. **Test → Test Explorer**
3. Run All / Debug All / right-click individual tests

Breakpoints in `.cs` files Just Work. Full variable inspection, step over/into, call stack.

## Running the agentic workflow

```bash
npm run agents
```
Opens Mastra Studio at **http://localhost:4111**.

**Flow:**

1. **Agents → Brainstorm (QA Analyst)** → chat: *"Let's design the test plan."*
2. Agent proposes 3-4 UI + 2 API tests with risk-based justifications. Iterate.
3. Type `approved` — agent writes `docs/01-test-plan.md` and auto-fires the workflow.
4. **Workflows → test-generation** — watch each step run:
   - **Architect** → `docs/02-architecture.md` (also auto-wipes stale agent artifacts first)
   - **Dev-UI** → `MoxymindTests/Pages/*.cs` + `MoxymindTests/Tests/UI/*.cs` + helpers (parallel with Dev-API)
   - **Dev-API** → `MoxymindTests/Tests/API/*.cs` + `MoxymindTests/TestData/users.csv` + `MoxymindTests/Schemas/*.json`
   - **Blind-Review** (parallel with Compliance Review) → `docs/03-blind-review.md`
   - **Compliance Review** → `docs/03-review.md`
   - **Gate** → suspends with both verdicts; you pick approve / reject / fix
5. On approve → **Report** writes `docs/README.md`
6. `cd MoxymindTests && dotnet test` → the generated suite runs

## Regeneration semantics (auto-clean)

Every workflow run starts clean. The architect step wipes stale agent artifacts before any dev agent writes a single file — guarantees no orphans from previous runs.

### Wiped on every run
- `MoxymindTests/Pages/*.cs`, `MoxymindTests/Tests/UI/*.cs`, `MoxymindTests/Tests/API/*.cs`, `MoxymindTests/Helpers/*.cs`
- `MoxymindTests/TestData/*.csv`
- `MoxymindTests/Schemas/*.json`
- `docs/02-architecture.md`, `docs/03-review.md`, `docs/03-blind-review.md`, `docs/README.md`
- Empty intermediate folders (e.g. `MoxymindTests/Helpers/Models/` if ever created)

### Never touched
- `MoxymindTests/Tests/UI/Manual/`, `MoxymindTests/Tests/API/Manual/` — your hand-written tests, agents cannot write there
- `MoxymindTests/MoxymindTests.csproj` — fixed scaffolding, never regenerated
- `docs/01-test-plan.md` — the workflow input (your approved plan)
- `src/mastra/**` — the agents themselves
- `playwright.config.ts`, `.env`, `package.json`, `README.md` — project config

## Adding your own tests

**Easiest — just talk to Brainstorm**:
> *"Also add a test that verifies the hamburger menu's Reset App State button clears the cart."*

Agent incorporates it into the plan. Dev-UI generates the C# test. No code changes.

**Hand-written — put under `Manual/`**:
```
MoxymindTests/Tests/UI/Manual/MyCustomTest.cs
MoxymindTests/Tests/API/Manual/MyRegression.cs
```
MSTest discovers both locations. Agents physically cannot write to `Manual/`.

## Design notes

- **Two languages, two jobs.** TypeScript is where the AI ecosystem lives (Mastra, Studio UI, AI SDK). C# is where the user's team debugs tests. Each tool for what it's best at.
- **Two model tiers.** Dev agents use Sonnet 5.5 (code quality matters); planning / review / report use Haiku 5.5 (~5× cheaper).
- **Prompt caching.** Shared system prompt is marked ephemeral-cacheable → ~90% off cached input tokens on reruns within 5 min.
- **Sandbox.** `writeFileTool` only accepts paths under `docs/**` or `MoxymindTests/{Pages,Tests,Helpers,TestData,Schemas}/**`. `MoxymindTests/.csproj` is read-only. `Manual/` subtrees are off-limits.
- **Hallucination guard.** Each workflow step checks disk after the agent returns — missing files = loud failure.
- **Auto-clean before every run.** `architectStep` wipes agent artifacts first. Prevents orphans. `Manual/` is sacred.
- **Two human gates.** Brainstorm approval + Review verdict (`approve` / `reject` / `fix` on both reviewers' findings).
